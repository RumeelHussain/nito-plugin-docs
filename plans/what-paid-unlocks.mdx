Nito has four plans: **Free**, **Plus**, **Advanced**, and **Max**. Your plan is account-wide, so it governs both the Nito app and the plugin. This page focuses on what each tier means for plugin users.

<Note>
Prices are set live and can vary by region and billing period. The snapshot below is a reference; open **Billing** in the Nito app for the current pricing on your account.
</Note>

## What Each Plan Adds

Each tier includes everything in the tier below it.

| Capability | Free | Plus | Advanced | Max |
| :-- | :--: | :--: | :--: | :--: |
| Monthly plugin requests | 10 / month | Included | Included | Included |
| Full model context windows | — | ✓ | ✓ | ✓ |
| Premium and frontier model access | — | ✓ | ✓ | ✓ |
| [Fusion](/commands/fusion) | — | ✓ | ✓ | ✓ |
| Nito Auto | — | ✓ | ✓ | ✓ |
| Prompt enhancement | — | ✓ | ✓ | ✓ |
| Encrypted backups | — | ✓ | ✓ | ✓ |
| Browser usage on eligible open-source models | — | ✓ | ✓ | ✓ |
| Beta model access | — | — | ✓ | ✓ |
| Live sync | — | — | ✓ | ✓ |
| Workbench (Knowledge, Prompts, Personas, Preview Context) | — | — | ✓ | ✓ |
| Unused credits roll over | — | — | 3 billing periods | 4 billing periods |

Some rows above (Workbench, Live sync, Encrypted backups, browser usage) are features of the Nito app rather than the plugin, but they come with the same plan, so they are listed for completeness.

## What Matters for the Plugin

Two plugin capabilities require a paid plan:

- **[Fusion](/commands/fusion)** runs one prompt across two or three models with a synthesis. It is available from **Plus** and up.
- **[Full Nito-routed sessions](/commands/session)** power an entire host session with a Nito model. These require a paid plan with full-session access enabled for your organization.

Everything else, one-off [`ask`](/commands/ask-and-continue) and [`private`](/commands/private) prompts, model selection, and status, works on the Free allowance until you run out. See [Free Usage](/plans/free-usage).

| :-- | :-- | :-- |

| Plus | $15 / month | $162 / year |
| Advanced | $50 / month | $540 / year |

Annual billing works out to roughly a 10% saving over paying monthly.
