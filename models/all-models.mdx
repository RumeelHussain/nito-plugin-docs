## How to Read This

Each model belongs to one privacy tier, which sets how private a call to it is:

- **Anonymous** gives the widest choice and metadata-only retention.
- **Private** adds an upstream provider held to zero data retention.
- **Confidential** runs in a sealed environment you can verify. Confidential models are listed with a `:confidential` marker on their name.

For what each tier guarantees, see [The Four Tiers](/privacy/tiers).

## Using a Model From the List

Set any of these as your default or use it for a single call:

<Tabs>
  <Tab title="Claude Code">
    ```text
    /nito:model anthropic/claude-sonnet-5
    /nito:ask --model openai/gpt-5.5 Summarize this thread.
    ```
  </Tab>
  <Tab title="Codex">
    ```text
    $nito:model anthropic/claude-sonnet-5
    $nito:ask --model openai/gpt-5.5 Summarize this thread.
    ```
  </Tab>
</Tabs>

Not sure which to pick? See [Choosing a Model](/models/choosing-a-model). To set defaults and switch models, see [Choosing a Model (commands)](/commands/choosing-a-model).
