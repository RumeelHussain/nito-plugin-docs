The models you can reach through the plugin, grouped by privacy level. This is a **snapshot**; the catalog is discovered live and changes over time, so use [`models`](/commands/choosing-a-model) for the authoritative list on your account.

<Note>
Snapshot of **2026-07-31**. **Price /1M** is USD per one million tokens, shown as **input · output**. The **privacy level** is shown as its own section, because [the level follows the model you choose](/privacy/tiers). See [Pricing](/models/pricing) for how cost is structured.
</Note>

Capabilities in the table:

- **reasoning** step-by-step thinking. See [Reasoning](/features/reasoning).
- **vision** image input. See [Image Input](/features/multimodal/image-input).
- **web** web search and fetch. See [Web Search](/features/server-side-tools/web-search).
- **attestable** supports a verifiable attestation. See [The Four Levels](/privacy/tiers).

## Using a Model From the List

Set one as your default, or use it for a single call:

<Tabs>
  <Tab title="Claude Code">
    ```text
    /nito:model anthropic/claude-sonnet-5
    /nito:ask --model openai/gpt-5.5 Summarize this thread.
    ```
  </Tab>
  <Tab title="Codex">
    ```text
    $nito:model anthropic/claude-sonnet-5
    $nito:ask --model openai/gpt-5.5 Summarize this thread.
    ```
  </Tab>
</Tabs>

Not sure which to pick? See [Choosing a Model](/models/choosing-a-model). For how model IDs are named, see [Model ID Convention](/models/model-id-convention). To set defaults and switch models, see [Choosing a Model (commands)](/commands/choosing-a-model).
