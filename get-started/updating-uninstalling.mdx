## How Versions Work

The command line tool and the plugin are always **version-matched**. Setup installs the plugin from the tool itself, so the two never drift apart. Updating one updates the other.

## Updating

```bash
nito update
```

This upgrades `nito` and refreshes your managed harness integrations in one step. To refresh only the integrations without upgrading the binary:

```bash
nito update --skip-binary
```

## Uninstalling

Removal is two parts: take the plugin out of your harness, then remove your credential.

<Steps>
  <Step title="Remove the plugin">
    <Tabs>
      <Tab title="Claude Code">
        ```bash
        claude plugin uninstall nito@nito
        ```
      </Tab>
      <Tab title="Codex">
        ```bash
        codex plugin remove nito@nito
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Remove your credential">
    Sign out to remove the local Nito credential from your keychain:

    ```bash
    nito agent logout
    ```
  </Step>
</Steps>

<Note>
Uninstalling the plugin and signing out does not delete your Nito account or stop any billing. Manage those from your account in the browser, see [Upgrade and Manage](/plans/upgrade-and-manage).
</Note>
