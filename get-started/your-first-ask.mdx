`ask` is the simplest Nito command. It sends one question through Nito and returns the answer inside your current chat. Your harness keeps running its own model and makes one Nito call when you ask.

<Note>
Type Nito commands **inside a running Claude Code or Codex session**, not at your terminal prompt. Typing `$nito:ask …` at a plain shell prompt will not work; your shell tries to interpret it and reports something like `no matches found`. Start your harness first, then run the command inside it.
</Note>

## See What's Available

The help command is a menu rather than a model call. It shows the Nito actions you can run:

<Tabs>
  <Tab title="Claude Code">
    ```text
    /nito:help
    ```
  </Tab>
  <Tab title="Codex">
    ```text
    $nito:help
    ```
  </Tab>
</Tabs>

## Run Your First Ask

<Tabs>
  <Tab title="Claude Code">
    ```text
    /nito:ask What is the capital of France?
    ```
  </Tab>
  <Tab title="Codex">
    ```text
    $nito:ask What is the capital of France?
    ```
  </Tab>
</Tabs>

You don't have to choose a model first. With no saved preference, `ask` uses a sensible default. The model picker is there for when you *want* to browse or switch, not something to set up before your first call.

## Read the Result Label

Every Nito result ends with a label telling you exactly what ran:

```text
Nito · <environment> · <model> · <privacy level> · <context scope>
```

A hosted plugin call looks like this:

```text
Nito · Hosted · MODEL-ID · private · Prompt only
```

- **environment**: where the call ran. Plugin calls read `Hosted`.
- **model**: the model that answered.
- **privacy level**: Anonymous, Private, Confidential, or Encrypted.
- **context scope**: how much of your conversation was shared. Prompt only, by default.

You never have to guess whether a call was private or which model answered. The label says so.

<Note>
`ask` is an ordinary turn in your chat, so it travels upstream with the rest of your conversation. When a question has to stay out of that, use [`private`](/get-started/your-first-private-prompt) instead.
</Note>

  </Tab>

## Set a Default

Two commands, both inside Claude Code or Codex. There is nothing to set up on a website.

<Tabs>
  <Tab title="Claude Code">
    ```text
    /nito:models          browse the catalog
    /nito:model           see your current default and change it
    ```
  </Tab>
  <Tab title="Codex">
    ```text
    $nito:models          browse the catalog
    $nito:model           see your current default and change it
    ```
  </Tab>
</Tabs>

Run `model` with no argument to see what you are on and pick from a list.

<Note>
`/nito:model` changes the model your future Nito calls use. It does not change the model running your session.
</Note>
