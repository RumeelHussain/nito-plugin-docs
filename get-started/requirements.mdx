## Your Harness

You need a working install of one of these.

| Harness | Minimum version |
| :-- | :-- |
| Claude Code | `2.1.214` or newer |
| Codex CLI | `0.144.5` or newer |

{/* PLACEHOLDER: confirm final launch minimums before public release. */}

**These minimums apply to full sessions only**, meaning `/nito:session`, `nito claude`, and `nito codex`. On an older version, a session launch stops and tells you the version you need. `ask` and `private` work on the harness you already have.

## Platform

- **macOS and Linux.** Fully supported.
- **Windows.** Supported. One difference: if a private session crashes, its temporary profile may sit on disk until the operating system clears it, rather than being removed on exit.

## Account

A **Nito account**. {/* PLACEHOLDER: sign-up link pending. */}

Free accounts get 10 asks or private questions a month. Fusion and full sessions need a paid plan. See [Plans and Billing](/plans/free-usage).

## The Command Line Tool

The `nito` tool has to be installed and on your `PATH`. It powers setup, file attachments, and private and session launches. Installing it is the first step of each install guide.
