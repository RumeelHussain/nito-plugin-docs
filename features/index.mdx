The Nito plugin is not just a way to send a prompt. The models behind it can search the web, read a page you name, parse a document you attach, look at an image, and think through a hard problem before answering. This section covers each capability and how to use it from the plugin.

Most features ride on top of the commands you already know, [`ask`](/commands/ask-and-continue), [`private`](/commands/private), and [`session`](/commands/session), and you turn them on with a flag. There is nothing extra to install.

## Capabilities Follow the Model

Two of these features, reasoning and image input, are not flags: they are properties of the model you choose. A model either supports reasoning (or vision) or it does not. Browse the catalog with [`models`](/commands/choosing-a-model) to see what each one supports, then pick a model that fits the task. Web search, web fetch, and document parsing work more broadly and are controlled with flags.

## A Note on Sessions

When you open a full Nito [`session`](/commands/session), your host's normal behavior, streaming replies and its own tool use, keeps working, now powered by a Nito model. Those are host-native behaviors rather than plugin flags, so they are covered where the session is: see [Session](/commands/session).

## From the Terminal

Every capability here also works from the `nito` CLI. See [Ask and Fusion from the Terminal](/cli/ask-and-fusion-from-terminal).
