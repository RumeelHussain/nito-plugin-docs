## Top Questions

**Do I type Nito commands in my terminal or inside the chat?**
Inside a running Claude Code or Codex session, not your terminal shell. The one exception is the `nito` [CLI](/help/faq/using-the-cli). See [Getting started](/help/faq/getting-started).

**Does using the plugin send my prompt to my host's model provider?**
It depends on the command. A plain `ask` runs in your host conversation, so your host can see it; `private` keeps a turn out of your host's upstream. See [Privacy](/help/faq/privacy).

**Does choosing a Nito model change my Claude or Codex model?**
No. It only changes what Nito uses for its own commands. See [Models and Fusion](/help/faq/models-and-fusion).

**Is the plugin free?**
Eligible free accounts get a monthly allowance of plugin requests. See [Plans and usage](/help/faq/plans-and-usage).
