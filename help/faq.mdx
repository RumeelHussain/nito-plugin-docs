## Basics

<AccordionGroup>
  <Accordion title="Do I type Nito commands in my terminal or inside the chat?">
    Inside a running Claude Code or Codex session, not your terminal shell. `/nito:ask` and `$nito:ask` are commands the host understands; your shell does not. The one exception is the `nito` [CLI](/cli/cli-overview), which does run in the terminal.
  </Accordion>
  <Accordion title="What is the difference between /nito: and $nito:?">
    Only the trigger. Claude Code uses `/nito:`, Codex uses `$nito:`. Every command exists in both hosts with the same behavior. See the [Command Index](/commands/command-index).
  </Accordion>
  <Accordion title="Do I need an API key?">
    No. The plugin signs in through your browser and stores the credential for you. You never paste a key into a chat, and Nito never asks for one there. See [Install](/get-started/install-claude-code).
  </Accordion>
  <Accordion title="Why did setup ask me to sign in twice?">
    Because there are two credentials: a **Local CLI** credential for local features, and a **Hosted** connection for the model calls. Setup authorizes both in the browser and skips either one that is already signed in, so you may only see one prompt.
  </Accordion>
  <Accordion title="Is Nito a model, or a gateway?">
    A gateway. Nito sits in front of many models and you choose which one answers per call. There is no single "Nito model." See [How It Works](/get-started/how-it-works).
  </Accordion>
</AccordionGroup>

## Privacy

<AccordionGroup>
  <Accordion title="Does using the plugin send my prompt to Claude's or Codex's provider?">
    It depends on the command. A plain `ask` runs inside your host conversation, so your host can see that prompt. `private` is the command built to keep a turn out of your host's upstream entirely. See [Ask](/commands/ask-and-continue) and [Private](/commands/private).
  </Accordion>
  <Accordion title="What does Private actually guarantee?">
    A `private` turn is not sent to your host's own model provider. What it does not do is turn off local disk writes or act as a sandbox by itself. The [Private](/commands/private) page spells out exactly what is and is not covered.
  </Accordion>
  <Accordion title="What are the privacy tiers?">
    Anonymous, Private, Confidential, and Encrypted. The tier follows the model you choose and never silently downgrades. See [Privacy Tiers](/privacy/tiers).
  </Accordion>
  <Accordion title="Can I verify the privacy claim myself?">
    Yes, for the attested tiers. Confidential runs in a Trusted Execution Environment and returns evidence you can verify independently, rather than asking you to take the claim on trust. See [TEE Attestation](/privacy/tee-attestation).
  </Accordion>
  <Accordion title="What does Nito keep about my prompts?">
    By default, metadata only. Prompt and completion contents are treated as request-local and are not persisted by the gateway. See [Zero Data Retention](/privacy/zero-data-retention).
  </Accordion>
</AccordionGroup>

## Models and Fusion

<AccordionGroup>
  <Accordion title="Does choosing a Nito model change my Claude or Codex model?">
    No. Setting a Nito model with `model` only changes what Nito uses for its own commands. Your host session keeps running on whatever model it was already using. See [Choosing a Model](/commands/choosing-a-model).
  </Accordion>
  <Accordion title="Can I ask several models at once?">
    Yes. `fusion` sends one prompt to two or three models and adds a synthesis that reconciles them. It needs a paid plan. See [Fusion](/commands/fusion).
  </Accordion>
  <Accordion title="How do I find the models available to me?">
    Run `models` inside a chat to browse the catalog for your account, or `nito agent models` from the terminal. The full catalog reference is in [Models](/models).
  </Accordion>
</AccordionGroup>

## Plans and Cost

<AccordionGroup>
  <Accordion title="Is the plugin free to use?">
    Eligible free accounts get a monthly allowance of plugin requests. When it runs out, upgrade to keep going. See [Free Usage](/plans/free-usage).
  </Accordion>
  <Accordion title="What does a paid plan unlock?">
    Higher limits plus the paid-only capabilities like Fusion and full Nito-routed sessions. See [What Paid Unlocks](/plans/what-paid-unlocks).
  </Accordion>
  <Accordion title="How do I check my usage?">
    Run `status` inside a chat for your plan and usage card, including any free-allowance notice. See [Checking Usage](/plans/checking-usage).
  </Accordion>
</AccordionGroup>

## Do I Need the CLI?

<AccordionGroup>
  <Accordion title="Do I need the nito CLI at all?">
    No, not for everyday prompting. The plugin does the work from inside your chat. The [CLI](/cli/cli-overview) is there for installing and repairing the integration, and for running Nito from the terminal or a script when you want to.
  </Accordion>
</AccordionGroup>
